Online Library
A React + Vite app for browsing and adding books. Uses React Router (dynamic routes), Redux Toolkit (state) and plain CSS.

Features
**Home** – welcome banner, category links, popular books
**Browse Books** – `/books` and `/books/:category`, plus title/author search
**Book Details** – `/book/:id` with a "Back to Browse" link
**Add Book** – validated form; stored in Redux; new book appears first after redirect
**404 page** – shows the invalid URL, no header, link back Home
